🎵 1. How to Add & Remove Playlists
Open index.html in your editor and locate CONFIG around line 699: 
const CONFIG = {
  YOUTUBE_MUSIC_PLAYLISTS: 'https://music.youtube.com/playlist?list=PLWfMLjZuX3nECAxZMzh1fTphRH1UxZvEj',
  YOUTUBE_PLAYLISTS: ''
};

To ADD a Playlist:
Add playlist URLs or Playlist IDs separated by commas in YOUTUBE_PLAYLISTS:

YOUTUBE_PLAYLISTS: 'PLK7o_bJ0788Vn7L--Hw0Y5G0c2R6-e7M2, https://www.youtube.com/playlist?list=YOUR_PLAYLIST_ID'

To REMOVE a Playlist:
Delete the URL or ID from the string, or set it to empty ''.

🚀 2. Deploying to Firebase Hosting

Open your terminal and run these two commands in order:

Step 1: Navigate to project directory:

cd C:\Users\Ishan\.gemini\antigravity\scratch\Garba-Jamming

Step 2: Deploy to Firebase:

npx firebase-tools deploy --only hosting

Your live web app URL: https://garba-jamming-app.web.app

⌨️ 3. Keyboard & Multimedia Hardware Shortcuts
  • Spacebar / K / Hardware Play-Pause: Toggle Play / Pause
  • N / ArrowRight / Hardware Next: Next Track
  • P / ArrowLeft / Hardware Previous: Previous Track
  • F: Toggle Full Screen
  • M / Hardware Mute: Toggle Mute
  • ArrowUp / ArrowDown: Adjust Volume (+5% / -5%)
🟢 4. Real-Time Live User Counter
  • Green pulsing dot on the topbar shows ● Live connected listeners right now.
  • Uses Firebase Realtime Database with 12s active session cutoff — when a user leaves or closes the tab, they are automatically removed in real time.
